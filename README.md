# 🛒 Shoppe - Full Stack E-Commerce Platform

Shoppe is a full-stack e-commerce application consisting of three modules:

- 🖥️ Admin Panel
- 🌐 Frontend Store
- ⚙️ Backend API

## 📂 Project Structure

```
shoppe/
├── e-commerce-admin/
├── e-commerce-frontend/
└── e-commerce-backend/
```

## 🚀 Features

### Frontend
- User-friendly shopping interface
- Product listing and details
- Shopping cart functionality
- Responsive design

### Backend
- RESTful APIs
- Product management
- User authentication
- Database integration

### Admin Panel
- Product management
- Order management
- Dashboard analytics
- Inventory control

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- MongoDB

### Admin
- React.js
- JavaScript

## 📦 Installation

### Clone Repository

```bash
git clone https://github.com/Sattarkhan37/shoppe.git
cd shoppe
```

### Frontend

```bash
cd e-commerce-frontend
npm install
npm run dev
```

### Backend

```bash
cd e-commerce-backend
npm install
npm start
```

### Admin Panel

```bash
cd e-commerce-admin
npm install
npm run dev
```
